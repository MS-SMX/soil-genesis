\# Filosofia del progetto



Soil Genesis non è un catalogo.



È un archivio vivente dedicato alla conservazione della biodiversità agricola.



Ogni elemento grafico deve avere anche una funzione.



Il tema cyberpunk è il linguaggio dell'interfaccia, non il contenuto.



Le schede devono essere leggibili anche in versione stampata.



Ogni dato deve essere scritto una sola volta.



Ogni informazione calcolabile deve essere generata automaticamente.
