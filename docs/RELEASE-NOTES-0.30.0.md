# Release notes · 0.30.0

- Aggiunta la pagina `qualita-dati-botanici.md` per individuare dossier senza famiglia botanica e/o ciclo di vita utilizzabile.
- Audit limitato alle collezioni semi, perenni e spontanee; include segnaposto espliciti come `da verificare` e `non classificata`.
- Aggiunti ricerca testuale, filtri per campo mancante e opzione per mostrare anche i dossier senza problemi rilevati.
- Ogni risultato offre un collegamento al dossier e, quando il percorso del file è disponibile, alla modifica su GitHub.
- Aggiunta interfaccia responsiva e documentazione sui limiti: nessuna inferenza botanica automatica e nessuna scrittura diretta dal sito statico.
- Build Jekyll e test browser da eseguire in ambiente con dipendenze installate.
