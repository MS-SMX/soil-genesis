# Soil Genesis

Archivio cibernetico-biologico dedicato alla conservazione delle sementi e all'agricoltura rigenerativa.

## Versione corrente

0.10.0

## Stato

Sviluppo attivo. L'archivio è statico e pubblicato tramite GitHub Pages; il diario di rigenerazione salva i dati nel browser e non sincronizza automaticamente tra dispositivi.

## Novità 0.10.0

- Aggiunta esportazione del diario di rigenerazione in JSON.
- Aggiunta importazione dei backup JSON, con controllo di formato e unione non distruttiva degli eventi.
- I duplicati con lo stesso identificativo vengono ignorati durante l'importazione.
- Chiarita nell'interfaccia la necessità di conservare il backup anche fuori dal browser.
