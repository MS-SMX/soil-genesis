# Soil Genesis 0.24.0 — Corrispondenze trasparenti

## Aggiunto
- Le schede fitosanitarie contestuali distinguono la corrispondenza per famiglia botanica da quella basata su nome comune, slug o identificativo.
- Le piante perenni non generano collegamenti fitosanitari destinati alla rotazione annuale.
- Alcuni avvisi di rotazione possono aggiungere promemoria operativi quando le note della parcella corrente menzionano esplicitamente ristagni, drenaggio scarso, irrigazione soprachioma, residui infetti o suolo/attrezzi contaminati.
- Nuovi test statici e documentazione dei limiti.

## Limiti
- I promemoria contestuali usano parole chiave nelle note, non un modello diagnostico o un punteggio di rischio.
- Il test suite verifica struttura e presenza dei comportamenti nel codice; non sostituisce una verifica browser reale.
- Build Jekyll completa non eseguita in questo ambiente.
