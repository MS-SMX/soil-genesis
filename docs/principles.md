# Soil Genesis Principles

## 1

Ogni dato deve poter essere verificato.

## 2

Nessuna informazione viene duplicata.

## 3

Le schede devono essere utilizzabili anche senza connessione.

## 4

Il design non deve ostacolare la consultazione.

## 5

Il codice deve rimanere compatibile con GitHub Pages.

## 6

Ogni funzionalità deve risolvere un problema reale di un custode di sementi.
