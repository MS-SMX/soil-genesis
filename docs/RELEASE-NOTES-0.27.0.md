# Release notes — 0.27.0

## Lettura temporale delle condizioni
- Aggiunto un riepilogo per parcella delle osservazioni datate, fino all'anno selezionato nella vista del Piano parcelle.
- Per drenaggio, irrigazione, residui e stato fitosanitario vengono mostrati l'ultimo valore registrato e il confronto con l'osservazione precedente dello stesso campo.
- I risultati distinguono cambiamento registrato, valore invariato, singola osservazione e campo senza dati.
- Il riepilogo rispetta il filtro della parcella; il registro cronologico annuale resta separato.

## Limiti
Il confronto è descrittivo. Non attribuisce i cambiamenti a pratiche specifiche, non diagnostica patogeni e non interpreta i campi mancanti come assenza. La data è quella inserita dall'utente. La build Jekyll e la verifica nel browser non sono state eseguite in questo ambiente.
